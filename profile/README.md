# Proxus

**Your entire industrial data stack. One product.**

Proxus is an industrial data platform that replaces the chain of separate tools between machines and business systems with one product. It reads PLCs, SCADA, meters and machines over 60+ native industrial protocols, gives every value one name, one unit and one place in an ISA-95 Unified Namespace, and keeps history, rules and alarms at the edge. Self-hosted: on premises, in a private cloud or fully air-gapped.
